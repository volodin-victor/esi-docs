# DSCAN-ICU

![](dscan-icu-ico.ico)

DSCAN-ICU — мощный инструмент, разработанный для игроков EVE Online для анализа, визуализации и обмена результатами направленного сканирования (D-Scan). Он помогает пилотам быстро интерпретировать данные сканирования, идентифицировать угрозы и координироваться со своим флотом. Инструмент доступен через веб и поддерживает интернационализацию (i18n) для глобальной аудитории.

## Возможности

- **Парсинг D-Scan**: Быстрый парсинг и анализ результатов D-Scan.
- **Визуализация**: Отображение данных сканирования в удобном для чтения формате.
- **Обмен**: Делитесь результатами сканирования со своим флотом или сообществом.
- **Поддержка i18n**: Полная поддержка нескольких языков для международных пользователей.
- **Экспорт данных**: Экспорт данных сканирования для дальнейшего анализа.
