# Диапазоны ID

Многие сущности в EVE имеют последовательный идентификатор.
Эти идентификаторы группируются в диапазоны в зависимости от типа сущности, которую они представляют.
Этот документ содержит диапазоны и сущности, которые они представляют.

Диапазоны включительные, то есть первый и последний ID в диапазоне являются действительными ID, однако (за исключением ID 0) первый ID обычно не используется.

Имейте в виду, что невозможно определить, является ли ID персонажем, так как персонажи, созданные до 2010-11-03, разделяют диапазоны ID с другими сущностями (корпорациями и альянсами).
